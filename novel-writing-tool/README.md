# 📚 Công Cụ Viết Truyện Tiểu Thuyết

Tool tạo cốt truyện và nhân vật tiểu thuyết một cách tự động và sáng tạo.

## ✨ Tính Năng

- **10 thể loại truyện**: Tình cảm, Hành động, Giả tưởng, Kinh dị, Hài hước, Trinh thám, Cổ trang, Tương lai, Huyền ảo, Lịch sử
- **6 bối cảnh khác nhau**: Hiện đại, Cổ trang, Tương lai, Trung cổ, Thời hoang khởi, Thế giới song song
- **Tùy chỉnh số lượng nhân vật**: Từ 1-10 nhân vật chính
- **4 độ dài truyện**: Ngắn, Trung bình, Dài, Sử thi
- **3 phong cách kể chuyện**: Ngôi thứ nhất, Ngôi thứ ba, Toàn tri
- **5 tông màu**: Tối & nghiêm trọng, Nhẹ nhàng & tích cực, Hài hước, Kịch tính, Bí ẩn
- **Yêu cầu bổ sung**: Tùy chỉnh thêm theo ý muốn
- **Xuất file**: Lưu truyện dưới dạng file .txt

## 🚀 Cách Sử Dụng

1. Mở file `index.html` trong trình duyệt
2. Chọn các tùy chọn cấu hình:
   - Thể loại truyện
   - Bối cảnh
   - Số lượng nhân vật (1-10)
   - Độ dài truyện
   - Phong cách kể chuyện
   - Tông màu
   - Yêu cầu bổ sung (tùy chọn)
3. Click nút "✨ Tạo Cốt Truyện"
4. Xem kết quả gồm:
   - Tổng quan truyện (tên, tagline, giới thiệu)
   - Danh sách nhân vật chi tiết
   - Cốt truyện theo chương
   - Thế giới & bối cảnh
5. Click "💾 Xuất File" để lưu truyện

## 📁 Cấu Trúc File

```
novel-writing-tool/
├── index.html      # Giao diện chính
├── style.css       # Styling
├── script.js       # Logic xử lý
└── README.md       # Hướng dẫn sử dụng
```

## 🎯 Kết Quả Đầu Ra

Tool sẽ tạo ra:

1. **Tổng quan truyện**: Tên truyện, tagline, và giới thiệu ngắn gọn
2. **Nhân vật chi tiết**: Mỗi nhân vật có:
   - Tên và vai trò
   - Tuổi
   - Tính cách
   - Nền tảng
   - Động lực
   - Diễn biến nhân vật
3. **Cốt truyện**: Phân chia theo chương với:
   - Khởi đầu
   - Diễn biến (tùy theo độ dài)
   - Cao trào
   - Hậu quả
   - Kết thúc
4. **Thế giới & bối cảnh**: Mô tả chi tiết về:
   - Địa điểm
   - Bầu không khí
   - Văn hóa
   - Điểm đặc biệt

## 💡 Mẹo Sử Dụng

- Thử nghiệm với các thể loại khác nhau để có kết quả đa dạng
- Điều chỉnh số lượng nhân vật để tạo độ phức tạp phù hợp
- Sử dụng phần "Yêu cầu bổ sung" để thêm yếu tố đặc biệt
- Xuất file để lưu trữ và chỉnh sửa sau
